# AI分享 个人软件分享网站

这是一个纯静态 HTML/CSS/JS 网站，风格采用第 4 种“暖色个人分享风”。

## 页面
- `index.html`：首页
- `software.html`：AI 软件列表
- `tutorials.html`：教程文档
- `download.html`：下载须知 / 下载入口
- `about.html`：关于我
- `admin.html`：网站管理页面

## 修改软件内容
1. 浏览器打开 `admin.html`，或者从网站导航点击“网站管理”。
2. 输入管理密码进入编辑页面。
3. 在页面中逐项修改软件名称、密码、两个下载链接、说明和使用步骤。
4. 在“软件图标”和“界面图片组”区域选择本地图片，界面图片支持多张。
5. 点击“添加软件”增加条目，点击每个条目右上角的“删除”减少条目。
6. 点击“导出 products.json”下载修改后的文件。
7. 用导出的文件替换网站目录里的 `data/products.json`。
8. 将修改后的文件上传到 GitHub，等待 GitHub Pages 更新。

## 修改页面文字内容
1. 打开 `admin.html` 并输入管理密码。
2. 在“页面内容”区域修改：
   - 首页内容
   - AI软件内容
   - 教程文档内容
   - 下载须知内容
   - 关于我内容
   - 首页二维码图片和二维码下方文字
   - 关于我二维码图片和二维码下方文字
3. 点击“导出 content.json”下载修改后的文件。
4. 用导出的文件替换网站目录里的 `data/content.json`。
5. 将修改后的文件上传到 GitHub，等待 GitHub Pages 更新。

## 直接保存到 GitHub
1. 打开 `admin.html` 并输入管理密码。
2. 在“保存到 GitHub”区域填写：
   - GitHub 用户名或组织
   - 仓库名称
   - 分支，通常是 `main`
   - 网站目录，网站放仓库根目录就留空
   - Fine-grained Token
3. 点击“测试连接”。
4. 连接成功后，点击“保存到 GitHub”。

Token 只保存在当前浏览器会话中，不会写入网站文件。仓库需要给 Token 开启 `Contents: Read and write` 权限。

## 搜索软件
首页、AI软件页面、下载须知页面都带有搜索框。

搜索会匹配：
- 软件名称
- 分类标签
- 版本号
- 软件说明
- 使用步骤

也可以点击“保存草稿”，把当前编辑内容暂存在本机浏览器中。

选择的图片会嵌入导出的 JSON 文件中，单张图片建议不超过 5 MB。

默认管理密码：`aifenxiang`

修改密码：打开 `assets/js/admin.js`，修改 `ADMIN_PASSWORD` 的值。

数据文件中的字段说明：
- `name`：软件名称
- `password`：查看下载链接所需密码
- `links`：最多两个下载链接，每个链接包含 `label` 和 `url`
- `desc` / `steps`：使用说明
- `icon`：软件图标路径或图片数据
- `previewImages`：软件界面多图，前台支持左右切换和双击放大

- AI 绘图工具：`pic888`
- 办公自动化助手：`office66`
- 视频处理工具箱：`video99`
